Units and dimensional consistency

Status: accepted (ADR 0008)

The solver uses SI internally and in YAML. v1.0 accepts SI only; any other unit system is a validation error, not a conversion. There is no hidden non-dimensionalisation. Benchmark cases use SI values that happen to correspond to the usual dimensionless set-up.

The contract is in ../protocols/units.md.

1. Conventions

quantity symbol SI unit
length, mesh coordinates \(x,y,z\) m
time \(t\) s
acceleration \(\mathbf{a}\) m/s²
velocity \(\mathbf{u}\) m/s
dynamic pressure \(p\) Pa = kg/(m·s²)
density \(\rho\) kg/m³
dynamic viscosity \(\mu\) Pa·s
kinematic viscosity \(\nu=\mu/\rho\) m²/s
temperature \(T\) K
thermal diffusivity \(\alpha=k/(\rho c_p)\) m²/s
body force per volume \(\mathbf{f}\) N/m³
cell volume \(V_P\) m³
face area \(A_f\) m²

Mesh coordinates are metres. There is no mesh.scale.

1a. YAML units declaration

Accepted in v1.0:

units:
system: SI

Also accepted, with the same meaning:

# no units block: SI is the default

Rejected in v1.0:

units:
system: CGS
units:
length: mm

The validation error says that only SI is implemented and that non-SI conversion is a future extension. No silent conversion occurs.

2. Dynamic pressure, not kinematic pressure

v1 stores

\[p \;[\mathrm{Pa}], \]

not \(p/\rho\). The incompressible momentum equation is

\[\rho\left(\frac{\partial \mathbf{u}}{\partial t} + \nabla\cdot(\mathbf{u}\otimes\mathbf{u})\right) = -\nabla p + \mu\nabla^2\mathbf{u} + \mathbf{f}, \]

or, divided by \(\rho\),

\[\frac{\partial \mathbf{u}}{\partial t} + \nabla\cdot(\mathbf{u}\otimes\mathbf{u}) = -\frac{1}{\rho}\nabla p + \nu\nabla^2\mathbf{u} + \frac{\mathbf{f}}{\rho}. \]

The pressure-correction equation is solved for a pressure correction \(p'\) with units of Pa; the velocity correction is

\[\mathbf{u} \leftarrow \mathbf{u} - \frac{\Delta t}{\rho}\nabla p'. \]

Storing dynamic pressure keeps the state ready for variable density and two-phase flow, where \(p/\rho\) is not a useful single variable.

3. Benchmarks in SI

For a lid-driven cavity with \(L=1\,\mathrm{m}\), \(U=1\,\mathrm{m/s}\), \(\rho=1\,\mathrm{kg/m^3}\):

\[Re = \frac{\rho U L}{\mu} \quad\Longrightarrow\quad \mu = \frac{\rho U L}{Re}. \]

For \(Re=100\), \(\mu=0.01\,\mathrm{Pa\,s}\), \(\nu=0.01\,\mathrm{m^2/s}\). The numerical values match the usual dimensionless case because the reference scales are one. The Reynolds number is a derived diagnostic:

Re = rho * U * L / mu

It is not a separate unit system.

4. Burgers and heat

Burgers:

\[\frac{\partial u}{\partial t} + \frac{\partial}{\partial x}\left(\frac{u^2}{2}\right) = \nu \frac{\partial^2 u}{\partial x^2}, \]

with \(u\) [m/s], \(\nu\) [m²/s]. The traveling wave is

\[u(x,t) = \frac{U}{2}\left[ 1 - \tanh\left(\frac{U(x-Ut/2)}{4\nu}\right) \right], \]

whose argument is dimensionless.

Heat:

\[\frac{\partial T}{\partial t} + \nabla\cdot(\mathbf{u}T) = \nabla\cdot(\alpha\nabla T) + S, \]

with \(T\) [K], \(\alpha\) [m²/s], \(S\) [K/s].

5. What not to do

  • Do not mix a dimensionless velocity with a dimensional pressure in one case.
  • Do not hard-code \(\rho=1\) without writing it in the case file.
  • Do not scatter conversion factors through kernels. v1.0 has no conversion; any future conversion belongs in the config binder, never in a kernel.
  • Do not add a units library to hot kernels; convert at the boundary only.

6. Future extensions

v1.0 accepts units.system: SI only. Later extensions can add:

  • units.system: CGS and a fixed unit table;
  • per-value suffixes such as 1.0 cm, 1.0e-3 Pa s;
  • mp-units or a small Quantity<Dimension> wrapper at the config and I/O boundary only.

The internal representation stays SI in every case.
