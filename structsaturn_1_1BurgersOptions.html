Detailed Description

Options for the 1D scalar Burgers solver.

The solver advances

du/dt + d/dx(u^2/2) = nu d2u/dx2 + source

on a structured 1D block. The initial and Dirichlet callbacks receive the physical point; Dirichlet also receives time so a moving exact solution can be imposed.
