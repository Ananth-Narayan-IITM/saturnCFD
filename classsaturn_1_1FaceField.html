Detailed Description

Face values for the six faces of each owned cell.

This is a cell-local face representation: (i,j,k,dir) is the face of cell (i,j,k) in direction dir (0 = -x, 1 = +x, ...). An internal face is therefore stored twice, once from each side, with opposite outward normals. That is exactly what cell-centred gradient/divergence loops need and avoids a global face-ownership map in the first implementation.
