Detailed Description

Steady 3D Stokes solver on a structured box.

The current core uses a PETSc DMDA with four cell-centred degrees of freedom (u,v,w,p). A 2D case uses the same core with nz = 1; the w rows are identity rows and w = 0. The coupled saddle-point matrix is solved with either a direct LU (validation reference) or GMRES/FGMRES and a fieldsplit/Schur preconditioner. The matrix is assembled with MatSetValuesStencil so the DMDA global numbering is respected on any multi-rank layout.
