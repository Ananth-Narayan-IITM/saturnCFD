Stokes validation

Status: implemented for 2D on 1/2/4/8 MPI ranks and 3D on 1/2/4. Results below are measured.

Solver: saturnStokes, coupled pressure–velocity saddle-point formulation. fieldsplit/Schur is the default linear solve; direct is the validation reference. Theory: ../theory/stokes.md and ../theory/coupledSaddlePoint.md.

1. Cases

case domain boundary conditions reference
Poiseuille 2D \([0,L]\times[0,H]\) no-slip walls, body force \(f_x=G\) or pressure drop analytic parabola
Poiseuille 3D \([0,L]\times[0,H]\times[0,W]\) no-slip walls, streamwise force analytic parabola in \(y\)
Couette 2D \([0,L]\times[0,H]\) lower wall at rest, upper wall \(U\) analytic linear profile
Couette 3D \([0,L]\times[0,H]\times[0,W]\) lower wall at rest, upper wall \(U\) analytic linear profile
MMS 2D periodic or Dirichlet box manufactured divergence-free velocity second-order velocity/pressure
MMS 3D periodic box manufactured divergence-free velocity second-order velocity/pressure
exit boundary 3D box/pipe with an outflow face no-slip walls, prescribed inlet, exit condition Sankhla & Das (2025)

The Poiseuille and Couette cases are the primary regression tests. The MMS cases verify the formal order. The exit-boundary case is the bridge to the 3D/BEM comparison and is scheduled after the first two tests pass.

2. Numerics

  • Cell-centred finite volume on a structured hexahedral box.
  • Coupled \(u,v,w,p\) saddle-point matrix; Brezzi–Pitkäranta pressure stabilisation.
  • PETSc MPIAIJ, GMRES/FGMRES, fieldsplit/Schur preconditioner.
  • Velocity block: GMRES + GAMG (production) or GMRES + ILU (serial-tuned); pressure block: preonly + GAMG or Jacobi.
  • Pressure nullspace for all-Neumann cases.
  • Tolerances: outer rtol = 1e-12, atol = 1e-14; velocity inner rtol = 1e-10; failure is an error.
  • Fully periodic cases use pressure and velocity gauges; both solvers are supported.

3. Error norms

For velocity and pressure separately:

\[L^2(\phi)=\sqrt{\frac{1}{N}\sum_P(\phi_P-\phi_P^{\mathrm{ref}})^2}, \qquad L^\infty(\phi)=\max_P|\phi_P-\phi_P^{\mathrm{ref}}|. \]

The pressure error is computed after removing the mean pressure. The discrete divergence norm is

\[\|D\|_2=\sqrt{\frac{1}{N}\sum_P\left(\nabla_h\cdot\mathbf{u}_h\right)_P^2}. \]

Source-consistent MMS

The mms case adds both the momentum source and the continuity source \(g = \nabla\cdot u_m - \beta\nabla^2 p_m\). Measured with direct LU:

case meshes velocity order pressure order
periodic 2D \(16^2 \to 32^2\) 2.01 1.89
periodic 3D \(8^3 \to 16^3\) 2.03 1.71
wall 2D \(16^2 \to 32^2\) 1.96 1.64
wall 3D \(16^3 \to 24^3\) 1.97 1.30
wall 3D \(24^3 \to 32^3\) 1.96 1.53

The wall 2D case is gated. The wall 3D pressure order is still rising with refinement (1.30 at 24³, 1.53 at 24³→32³), so the 3D wall case is measured but not gated. The top-wall continuity row previously had a sign error in the one-sided divergence; fixing it reduced the wall MMS pressure error by about an order of magnitude.

A fully periodic Stokes problem has a constant-velocity nullspace; the order test removes the mean velocity error. Fully periodic domains now use tiny pressure and velocity gauges (1e-6) so both the direct and fieldsplit paths are nonsingular; the fieldsplit periodic MMS is part of the regression suite. The pressure pin is shifted to match the manufactured pressure at the reference cell. The wall-bounded MMS variant is implemented and its sources pass a finite-difference check, but the wall pressure order is still under investigation, so it is not part of the gated test yet.

The z-dependent body-force sampling and the per-volume row scaling were also fixed: the old momentum rows were volume-integrated while the continuity rows were per-volume, which scaled the solved pressure by the cell volume and made the Schur complement O(1/(mu h^3)). MMS and the Sankhla & Das exit-boundary cases remain planned.

6. Reproduction

cd examples/saturnStokes
python3 validate.py --dim 2d --cli saturnCPU
python3 validate.py --dim 3d --cli saturnCPU # all cases + figures
python3 validate.py --dim both --cli saturnCPU # combined summary
ctest --preset solver

With output.vtkEvery: 1, each case writes one .vtu containing u, v, w and p for ParaView. validate.py writes the organized results/<dim>/figures/ tree: per-case validation/solver figures and the wall-MMS convergence plot. The 2D validation plots show the fields and the averaged profile; the 3D version shows velocity-profile surfaces for the numerical solution, the analytic solution and their error.
