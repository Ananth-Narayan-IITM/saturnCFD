Detailed Description

Options for the steady Stokes solver.

The collocated system is

-mu lap(u) + grad(p) = f, div(u) - beta lap(p) = 0,

where the pressure term is the Brezzi-Pitkaranta stabilisation that damps the checkerboard mode of the raw collocated divergence. stabilization sets the physical coefficient beta = stabilization * h_min^2 / mu; the assembly is per unit volume, so the discrete Laplacian uses beta / h^2. All four equations use the same per-volume scaling, which keeps the pressure physical and the Schur complement well conditioned.
