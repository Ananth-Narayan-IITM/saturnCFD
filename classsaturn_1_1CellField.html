Detailed Description

A cell-centred field with a local ghost layer, backed by Kokkos.

Storage is local and ghosted:

nxg = nx + 2*nGrow, nyg = ny + 2*nGrow, nzg = nz + 2*nGrow index(i,j,k,c) = c*nxg*nyg*nzg + kk*nxg*nyg + jj*nxg + ii

where ii = i - (origin[0] - nGrow), and similarly for j/k. The global (i,j,k) index is kept in the accessor so kernels and halo operations share one convention with MeshPartition/HaloExchange.
