Detailed Description

Static solver registry. A solver registers a factory by name; the CLI and tests create it without a runtime plugin.

Two factory kinds are supported:

  • Factory builds a solver with no case data (unit tests);
  • CaseFactory builds a solver from a validated YAML case (CLI runs).

A solver registered for the CLI also supplies its ConfigSchema, so -dumpConfig, -checkConfig and saturnCFD case.yaml use exactly the same option list.
