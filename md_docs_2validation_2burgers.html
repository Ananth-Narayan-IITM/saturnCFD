Burgers validation — 1D scalar saturnBurger

Solver: saturnBurger (class saturn::SaturnBurger)

Equation: \(\partial_t u + \partial_x(u^2/2) = \nu\partial_{xx}u\)

Case: tests/regression/burgers/traveling64.yaml

Reproduction: python3 tools/validateBurgers.py

This page records the analytic validation of the 1D solver. The reference is the exact viscous traveling wave

\[u(x,t)=\frac{U}{2}\left[ 1-\tanh\left(\frac{U(x-x_0-Ut/2)}{4\nu}\right)\right], \qquad U=1,\ \nu=0.02,\ x_0=0, \]

on \(x\in[-1,1]\) up to \(t=0.5\) s. Dirichlet boundary data follow the wave; the initial state is the same wave at \(t=0\).

The observed order is close to two at every refinement. The error at the finest grid is \(7.3\times10^{-6}\) in \(L^2\) and \(3.2\times10^{-5}\) in \(L^\infty\), out of a unit-amplitude wave. This is the expected truncation error of a second-order scheme, not a rank or boundary artefact.

Rank independence

At \(N=256\), 1, 2 and 4 ranks produce the same discrete solution:

ranks \(L^1\) \(L^2\) \(L^\infty\)
1 5.173840745110388e-05 1.2363783241939333e-04 5.062617877850117e-04
2 5.173840745110388e-05 1.2363783241939333e-04 5.062617877850117e-04
4 5.173840745110388e-05 1.2363783241939333e-04 5.062617877850117e-04

The relative \(L^2\) difference is exactly zero. The earlier \(\sqrt{n_{\rm ranks}}\) growth was caused by the validation diagnostic dividing by the local owned-cell count instead of the global count; the solver RHS, halo exchange and reduction were already rank independent.

Standalone example

A user-facing case lives in examples/saturnBurger/:

cd examples/saturnBurger
saturnCFD saturnBurger.yaml
python3 compareAnalytic.py

It uses 256 cells on \([0,1]\), \(x_0=0.25\), \(U=1\), \(\nu=0.02\) and \(t=0.5\) s, so the wave is away from both boundaries. compareAnalytic.py re-reads the case parameters, recomputes the \(\tanh\) solution independently and checks:

L1 error : 2.421051e-05
L2 error : 4.225856e-05
Linf error : 1.362376e-04
PASS: L2 4.225856e-05 <= tolerance 1.0e-04

It also writes results/saturnBurger/comparison.png. The raw final-time field is results/saturnBurger/traveling.csv (x,u_numerical,u_exact,error); the JSON summary includes wallSeconds. The CTest slice checks this example with burgers_example.

Verdict

The 1D scalar saturnBurger solver is fully validated for this phase:

  • it matches the analytic traveling-wave solution with a clean second-order convergence rate;
  • the error is rank independent and, in exact arithmetic terms, identical on 1/2/4 ranks;
  • it conserves and bounds the periodic inviscid shock;
  • it is registered and runs through a proper YAML case.

The remaining loop-related item is to extend the same solver to 2D/3D, which is deliberately deferred.
