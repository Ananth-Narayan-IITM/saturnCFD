Solver implementation sequence

Status: accepted. Phase 0 (PETSc) and the explicit part of Phase 1 (solver lifecycle, registry, time loop, SSP-RK) are implemented. Implicit BE/CN/BDF2 arrive with the PETSc diffusion solve in Burgers/heat. Burgers is next.

This page records the order, decisions and exit criteria for the solver work. It is the working checklist; the theory pages contain the derivations.

Decision summary

  1. Burgers first, then heat, then Stokes, then incompressible Navier–Stokes.
  2. PETSc first as a small linear-algebra phase, before any solver depends on it. The library target is saturnLinAlg.
  3. Burgers starts 1D scalar, then 2D and 3D scalar, then vector Burgers.
  4. Advanced convection waits until Burgers is validated. Current schemes are upwind, Rusanov and MUSCL/TVD with minmod, van Leer and superbee.
  5. Implicit diffusion uses PETSc; explicit Burgers is the first numerical validation, then IMEX/backward-Euler diffusion.
  6. Stokes and Navier–Stokes use pressure–velocity coupling; that is not part of the Burgers/heat phases.
  7. The PETSc solver wrapper is saturn::KspSolver; no home-grown Krylov solver.

Why Burgers first

  • It has an exact viscous traveling-wave solution.
  • It exercises nonlinear convection, limiters, time integration, diffusion, boundary ghosts, conservation and MPI.
  • It is the bridge to Navier–Stokes: same convective term and diffusion, no pressure or continuity.
  • A failure is local to the scalar operator/time/BC layer, not ambiguous with saddle-point pressure coupling.
  • The project documentation already defines it as the first solver and the traveling64 regression.

Heat comes second because it is linear and isolates implicit diffusion and PETSc. Stokes comes after both because it adds the saddle-point system, pressure nullspace and fieldsplit/Schur preconditioning.

Phase 2 — Burgers

Status: 1D/2D/3D scalar saturnBurger implemented and tested, with VTK and checkpoint/restart. Implicit diffusion is next.

Start with 1D scalar conservative Burgers:

\[\partial_t u + \partial_x\left(\frac{u^2}{2}\right) = \nu\partial_{xx}u + s . \]

Implemented:

  • src/solvers/saturnBurger/ target saturnBurger for 1D, 2D and 3D;
  • 2D conservative form with flux vector \(\mathbf{F}(u)=(u^2/2,u^2/2)\);
  • burgersFlux with canonical face orientation and Rusanov/local Lax–Friedrichs;
  • MUSCL/TVD reconstruction with minmod, van Leer and superbee;
  • explicit SSPRK3 (forward Euler and SSPRK2 also available);
  • Dirichlet and periodic boundaries; Neumann is next;
  • time-dependent Dirichlet data via Solver::setTime;
  • shared non-orthogonal Laplacian for diffusion;
  • constant source;
  • registered CLI solver with a YAML case, CSV profile and JSON summary.

Phase 3 — Heat equation

  • BE first, then CN/BDF2.

Still open: implicit BE/CN/BDF2 diffusion, Neumann boundaries and the 1D erf/boundary-layer cases.

Phase 4 — Stokes and pressure–velocity coupling

\[-\nabla p + \mu\nabla^2\mathbf{u}=\mathbf{f}, \qquad \nabla\cdot\mathbf{u}=0. \]

Chosen method: fully coupled saddle point, not SIMPLE/SIMPLEC.

  • Collocated FVM and Rhie–Chow face flux.
  • One MPIAIJ block with u,v,w,p (3D) or u,v,p (2D) per cell.
  • PETSc coupled direct LU for the validation core; GMRES/FGMRES + fieldsplit/Schur is the production path being tuned.
  • One pressure reference row fixes the constant gauge.
  • The same block is reused inside Navier–Stokes Picard/Newton or time steps.

Status: implemented. Poiseuille/Couette 2D/3D pass; 2D runs on 1/2/4 ranks; 3D is serial-validated. MMS, exit-boundary cases and 3D multi-rank DMDA assembly remain. Details: ../theory/coupledSaddlePoint.md, ../theory/stokes.md.

Validation: Poiseuille/Couette 2D/3D measured; MMS and exit-boundary cases planned.

Exit: 2D/3D examples reproduce the analytic profiles; the production fieldsplit path and 3D MPI remain open. reproduce the analytic profiles.

Phase 5 — Incompressible Navier–Stokes

  • Reuse the coupled saddle-point block with Picard/Newton linearisation.
  • Add convection to the velocity block; mass matrix for time stepping.
  • PISO transient and SIMPLE steady remain optional segregated paths.
  • Cavity \(Re=100,1000\) against Ghia et al.
  • Taylor–Green energy decay and order.

Numerical choices

term first choice later
diffusion matrix orthogonal part in PETSc matrix; non-orthogonal correction deferred full correction in matrix/iterated
time BE for first implicit step CN, BDF2
explicit convection SSP-RK3 —
IMEX BE/CN convection-explicit, diffusion-implicit higher-order IMEX
convection MUSCL + minmod/van Leer/MC WENO5 after Burgers validation
pressure coupled saddle point with PETSc fieldsplit/Schur SIMPLE/SIMPLEC optional path

Advanced convection (WENO5, MUSCL-Hancock, HLLC/AUSM) is deliberately deferred until Burgers is validated. Adding schemes before a validated baseline makes debugging harder.

Open decisions

  1. Burgers 1D scalar first (recommended) versus 3D vector first.
  2. IMEX BE versus fully implicit Newton for the first implicit Burgers step.
  3. Whether the first production matrix assembler uses a contiguous local numbering with an owner map or PETSc DMDA for the structured block. The current plan is a local-to-global map with ghost coverage; DMDA remains an alternative for a later optimisation.

Resolved: pressure coupling uses the coupled saddle-point/fieldsplit path for Stokes and Navier–Stokes. SIMPLE/SIMPLEC are fallback/optional segregated methods, not the primary design.
