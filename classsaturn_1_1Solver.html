Detailed Description

A scalar/vector PDE solver driven by the generic time loop.

The solver owns its state and exposes the explicit right-hand side du/dt = rhs(u). The time loop handles the stage combination and the boundary refresh. Implicit schemes are represented in TimeScheme but are enabled only when a solver provides an implicit diffusion solve.
