Phase 1 status and remaining work

The FV Poisson matrix assembler, implicit BE/CN/BDF2, Burgers/heat solvers and GPU execution verification are next. The parallel design is in mpiGpuDesign.md; the solver sequence is in solverSequence.md.

Recommended order

The solver-specific sequence is in solverSequence.md: PETSc Phase 0 (done), solver lifecycle, Burgers 1D→2D→3D, heat, Stokes, Navier–Stokes. The list below is the repository build-out order.

  1. Parallel decomposition and halo — host MPI slice done
    • MeshPartition from MPI_Dims_create/MPI_Cart_create.
    • one owner per cell, two ghost layers, 26-neighbour exchange.
    • periodic local copies before remote exchange.
    • host-staged pack/unpack and MPI_Isend/Irecv.
    • tests on 1, 2 and 4 ranks; analytic periodic field.
    • MPI test main with global failure reduction.
    • Done: Kokkos CellField adapter and host-staged device halo.
    • Remaining: CUDA build on a machine with the toolkit, rank-to-device mapping, halo/stencil benchmark, ASan/UBSan and compute-sanitizer.
  2. Finite-volume layer — first slice done
    • Done: Kokkos CellField with local ghost storage and components.
    • Done: CartesianGeometry device geometry (uniform block).
    • Done: FieldHalo device pack/unpack, local periodic copies.
    • Done: orthogonal laplacian; periodic 2D/3D MMS at order 2 on 1/2/4 ranks.
    • Done: GPU-labelled regression cases (active CUDA space, 32^3 MMS against the CPU reference, halo roundoff).
    • Done: LocalMesh structured geometry, FaceField, interpolate, gradient, divergence, Dirichlet/Neumann ghost fill.
    • Done: non-orthogonal Laplacian correction; exact for a sheared linear field.
    • Done: faceNormalVelocity, upwind/Rusanov/MUSCL convection with minmod, van Leer and superbee.
    • Done: linear exactness, periodic gradient/divergence MMS, upwind/MUSCL convection, advection–diffusion MMS, TVD step boundedness and the divergence theorem on a sheared mesh.
    • Done: simplified Rhie–Chow flux; zero for a linear pressure, suppresses a checkerboard pressure.
    • Next: pressure Poisson/SIMPLE-PISO with PETSc.
    • Next: persistent face flux and the momentum-diagonal Rhie–Chow coefficient.
    • Remaining: CUDA execution on a host with the toolkit.
    • MMS methodology: ../theory/manufacturedSolutions.md.
    • plan: fvmKokkosPlan.md, ADR 0016.
  3. Solver lifecycle and skeleton — explicit part done
    • Done: Solver interface, SolverRegistry, TimeControl.
    • Done: Simulation with forward Euler, SSPRK2 and SSPRK3.
    • Done: src/simulation diagnostics and stage workspaces.
    • Next: implicit BE/CN/BDF2 with the PETSc diffusion solve.
    • src/solvers/saturnBurger 1D solver — done.
    • addSolver(saturnBurger) and registry entry — done.
    • -listSolvers, -dumpConfig saturnBurger, -checkConfig and saturnCFD case.yaml — done.
    • 2D/3D extension, options, createFields, equations, diagnostics.
    • saturnCFDSolver saturnBurger saturnMyBurger (C++ tool).
    • boundary/fields YAML schema and validation.
  4. PETSc wrapper — Phase 0 done
    • saturnLinAlg, PetscScope, KspSolver.
    • pkg-config fallback for Debian PETSc.
    • done: 1D/3D Poisson, all-Neumann nullspace on 1/2/4 ranks.
    • next: FV Poisson matrix assembly from LocalMesh.
    • next: block/multi-RHS and fieldsplit/Schur.
  5. I/O completion
    • CSV diagnostics, run manifest, checkpoint.
    • checkpoint/restart test.

Then Phase 2: Burgers physics and the traveling64 analytic regression.

Exit criteria for the next increment

  • Done: Kokkos halo matches an analytic periodic field on 1, 2 and 4 ranks, including two ghost layers and all 26 directions.
  • Done: periodic 2D/3D manufactured Laplacian shows order 2 on 1, 2 and 4 ranks, and the 32^3 reference norm is stored.
  • Done: LocalMesh interpolation/gradient/divergence are exact for a linear field with Dirichlet ghosts, and periodic gradient/divergence MMS is second-order on 1/2/4 ranks.
  • Done: Neumann ghosts reproduce the exact linear gradient.
  • Done: non-orthogonal Laplacian is exact for a linear field on a sheared mesh.
  • Done: upwind convection and steady advection–diffusion MMS are first order on 1/2/4 ranks.
  • Done: MUSCL improves the L2 order to about 1.6 (minmod/van Leer) and keeps a periodic step bounded with all three limiters.
  • Done: the discrete divergence theorem holds on a sheared mesh.
  • Done: the Rhie–Chow correction vanishes for a linear pressure and suppresses a checkerboard pressure.
  • Done: PETSc 3.19.6 links through saturnLinAlg; 1D/3D Poisson and all-Neumann tests pass on 1/2/4 ranks.
  • Done: Solver, SolverRegistry, TimeControl and the explicit Simulation loop; constant/cosine/sine cases pass on 1/2/4 ranks.
  • Done: saturnBurger 1D scalar; traveling wave N=32->1024 with orders 1.98/2.11/2.10/2.06/2.03, periodic shock bounded/conservative, and bitwise identical results on 1/2/4 ranks at N=256.
  • Done: YAML CLI path (saturnCFD case.yaml), CSV profile and JSON summary; ctest --preset burgers passes on 1/2/4 ranks.
  • Pending: FV Poisson matrix assembly, implicit BE/CN/BDF2, 2D/3D Burgers and heat solvers.
  • Pending: pressure Poisson/SIMPLE-PISO with PETSc.
  • 1/2/4-rank cross-run results agree; a CUDA build reproduces the CPU reference within precision.
  • mpirun -np 1 GPU runs the halo/stencil benchmark.
  • tests/fv passes on a structured hex mesh with non-uniform geometry.
  • Dirichlet and Neumann Laplacian MMS isolate the physical-boundary order.
  • saturnCFD -listSolvers lists saturnBurger.
  • saturnCFD -dumpConfig saturnBurger -writeTemplate burgers produces a template that passes -checkConfig.
  • saturnCFDSolver saturnBurger saturnMyBurger will create a buildable copy and print addSolver(saturnMyBurger) when the scaffold tool lands.
