Detailed Description

fv

Shared finite-volume operators. Every solver uses this layer; none of them reimplements a gradient or a flux.

Implemented

  • CellField — ghosted cell-centred Kokkos view with ncomp components and nGrow ghost layers. Global (i,j,k,c) indexing matches MeshPartition and HaloExchange.
  • FaceField — six face values per owned cell, (i,j,k,dir,c). Internal faces are stored from both sides; this is the cell-local representation the gradient and divergence loops need.
  • LocalMesh — structured local geometry extracted from the global hex mesh: cell volume/centroid, outward face area/normal/centroid, centroid-to-face distance and boundary patch index for the six faces of every owned cell. Device views plus host mirrors.
  • FieldHalo — Kokkos halo adapter: device pack, host mirror, MPI Isend/Irecv, device unpack, plus local periodic copies. Buffers are allocated once, not inside a time loop.
  • fillBoundaryGhosts — physical Dirichlet/Neumann ghost fill after the periodic/partition halo. Periodic directions and inactive 2D directions are skipped.
  • interpolate — linear cell-to-face interpolation.
  • gradient — Gauss gradient, (1/V) sum_f phi_f A_f n_f.
  • divergence — (1/V) sum_f F_f A_f; a three-component face field is dotted with the normal, a one-component field is already the normal flux.
  • laplacian on LocalMesh — non-orthogonal corrected face-normal gradient: [(phi_N-phi_P) - d . grad_tang] / (d . n). Boundary faces use the interpolated face value and the owner-gradient tangential correction.
  • CartesianGeometry + laplacian — uniform-block orthogonal seven-point operator, kept for the periodic Laplacian MMS.
  • faceNormalVelocity — interpolate a cell velocity and take its outward normal component.
  • convectiveFlux — upwind, Rusanov and MUSCL face fluxes. MUSCL uses a limited linear reconstruction with minmod, van Leer or superbee. For scalar advection the Rusanov flux is algebraically identical to upwind; the branch is kept for the system/vector extension.
  • rhieChowFlux — simplified Rhie–Chow face-normal velocity: average(u).n + c[(p_N-p_P)/d_perp - grad(p)_f.n]. The coefficient c is caller-supplied until the momentum diagonal exists.

Current limitations

  • LocalMesh supports structured hexahedral meshes only.
  • Interpolation uses centroid distances on internal, periodic and partition faces when the ghost centroid is available. Physical boundary faces use equal weights, which is exact for the mirror ghosts used by Dirichlet and Neumann fill.
  • Boundary fill runs through host mirrors in this CPU-first slice. The device path is the same API but not yet optimized.
  • Corner ghosts (two/three boundary directions) are not filled; current operators read face-neighbour ghosts only.
  • The non-orthogonal Laplacian uses the interpolated gradient on owned-owned faces, but the owner gradient on partition/periodic ghost faces. That is exact for a linear field; a ghost-cell gradient reconstruction is a later refinement for smooth fields on strongly skewed partitioned meshes.
  • Periodic ghost centroids use the lattice vector estimated from the first two cells in each direction. That is exact for a uniform or uniformly sheared periodic mesh; a non-uniform periodic mesh needs per-image period vectors.
  • FaceField is temporary/workspace storage. A persistent face-flux field for pressure correction comes later.
  • MUSCL uses the first-order upwind value on physical-boundary faces and on internal faces whose upwind reconstruction would need an uninitialised physical ghost. Two ghost layers are required.
  • MUSCL/TVD clips smooth extrema, so the L2 order is about 1.5 in the sinusoidal MMS; minmod/van Leer are less compressive than superbee.
  • rhieChowFlux is only the face-flux operator. The pressure Poisson solve and the SIMPLE/PISO loop are not implemented; they belong to the PETSc layer.

Next

  • Pressure Poisson/SIMPLE/PISO coupling with PETSc, using the Rhie–Chow flux.
  • A persistent face-flux FaceField.
  • Boundary-condition YAML schema and patch selection.
  • Momentum/Rhie–Chow coefficient from the momentum diagonal.

Boundaries

  • No solver lifecycle, no YAML parsing, no file I/O.
  • Operators take fields and geometry; no hidden allocation in a time loop.
  • No unit conversion: fields are SI.

Tests

  • tests/TestFv.cpp — CellField fill/reduce, Kokkos halo on two periodic ghost layers, 2D/3D manufactured Laplacian order, CPU reference norm, CUDA cases.
  • tests/TestLocalMesh.cpp — LocalMesh geometry, linear interpolation, Dirichlet and Neumann ghost fill, gradient/divergence exactness, sheared-mesh non-orthogonal Laplacian exactness, upwind/MUSCL convection, advection–diffusion MMS, TVD step boundedness, divergence theorem and Rhie–Chow flux checks on 1/2/4 ranks.
  • ctest --preset fv runs the FV binary on 1, 2 and 4 ranks.
