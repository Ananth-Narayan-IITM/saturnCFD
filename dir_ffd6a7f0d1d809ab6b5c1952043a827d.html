Method

  • Collocated cell-centred u,v,w,p on a PETSc DMDA.
  • Coupled saddle-point matrix:

    \[ \left[\begin{array}{cc} A & -B^{T}\\ B & C\end{array}\right] \left[\begin{array}{cc}\mathbf{u}\\p\end{array}\right] = \left[\begin{array}{cc}\mathbf{f}\\0\end{array}\right]. \]

  • A Brezzi-Pitkaranta pressure Laplacian C = beta lap(p) replaces the raw collocated divergence; one pressure reference row fixes the constant gauge.
  • Row scaling: every equation is assembled per unit volume. Momentum diffusion is mu/h^2, the pressure gradient and divergence are 0.5/h, and the stabilisation is beta/h^2 with beta = stabilization * h_min^2 / mu. This makes the discrete gradient the negative transpose of the divergence, keeps p physical, and gives a Schur complement of order 1/mu instead of 1/(mu h^3).
  • Matrix numbering: the matrix is inserted with MatSetValuesStencil. Hand-built PETSc ids from i + nx*(j + ny*k) are only correct when the DMDA is split along x; on y/z splits they disagree with the DA global ordering. The fieldsplit index sets are built from the matrix block owner range for the same reason.
  • stokes.linearSolver defaults to fieldsplit, which needs only O(N) memory: outer FGMRES, PC_COMPOSITE_SCHUR with fact_type full and selfp, GMRES + GAMG on the velocity block (rtol 1e-10), and preonly + GAMG on the pressure block. The outer tolerance is 1e-12. The sub-solver choices are schema keys: stokes.velocityKsp, stokes.velocityPc, stokes.pressureKsp, stokes.pressurePc. examples/saturnStokes/*/compareSolvers.py compares time, memory and accuracy against direct LU; see docs/validation/fieldsplit.md. This gives 11-20 outer iterations in 2D and 3-13 in 3D on 1/2/4/8 ranks. direct selects PETSc preonly + lu (SuperLU_DIST when available; MUMPS can report a false zero pivot on small multi-periodic saddle-point systems) and is retained for validation or users with enough memory.
  • 2D cases use the 3D core with nz = 1; w is constrained to zero.
  • 2D runs on 1/2/4/8 ranks and 3D on 1/2/4 ranks; the 3D tests no longer skip multi-rank runs. A fieldsplit-vs-direct test guards the default solver.
  • Fully periodic domains use small pressure and velocity gauges; both direct and fieldsplit are supported.

Cases

stokes.case:

  • poiseuille — body force forceX = G, exact \(u=G/(2\mu)y(H-y)\);
  • couette — moving top wall wallVelocityX = U, exact \(u=Uy/H\);
  • mms — source-consistent manufactured solution. stokes.mmsWall: false (default) is fully periodic; true selects a wall-bounded variant. The wall variant is gated in 2D (velocity 1.96, pressure 1.64); the 3D wall pressure order is measured (1.53 on 24³→32³) but not yet gated.

The core requires periodic x and z; y is either a wall pair or periodic (stokes.periodicY for MMS).

Running

./buildCPU/saturnCFD examples/saturnStokes/saturnStokes2D/poiseuille.yaml
./buildCPU/saturnCFD examples/saturnStokes/saturnStokes3D/poiseuille.yaml

Output is CSV (x,y,z,u,v,w,p,u_exact,v_exact,w_exact,p_exact,error) and JSON (iterations, residual, exact norms) under output.prefix. When output.vtkEvery > 0, one .vtu file contains all four cell arrays u, v, w, p for ParaView.

MMS

The mms case supplies the momentum source f = -mu lap(u_m) + grad(p_m) and the continuity source g = div(u_m) - beta lap(p_m). Both manufactured velocities are divergence-free, so g = -beta lap(p_m). The pressure is shifted so the reference cell has p = 0; a fully periodic problem is still defined only up to a constant velocity, so the order test removes the mean velocity error.

Fully periodic domains add tiny pressure and velocity gauges (1e-6) to remove both nullspaces; wall cases keep the pressure reference row, so p = 0 is exact. Both solvers handle periodic cases. Measured orders:

case meshes velocity order pressure order
periodic 2D 16 \(^2\) -> 32 \(^2\) 2.01 1.89
periodic 3D 8 \(^3\) -> 16 \(^3\) 2.03 1.71
wall 2D 16 \(^2\) -> 32 \(^2\) 1.96 1.64
wall 3D 16 \(^3\) -> 24 \(^3\) 1.97 1.30
