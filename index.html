saturnCFD

Structured finite-volume CFD for scalar transport, Stokes flow and incompressible Navier–Stokes, driven by YAML and validated against analytic solutions.

Status: Phase 1 in progress. Mesh, checkMesh, SI-only validation, yaml-cpp schema validation, CLI help, VTK mesh export, MPI partition/halo and the CPU Kokkos FVM slice (CellField, FaceField, LocalMesh, interpolation, gradient, divergence, non-orthogonal Laplacian, boundary ghosts, upwind/Rusanov/MUSCL convection, MMS and a simplified Rhie–Chow flux), the Phase 0 PETSc saturnLinAlg layer, the explicit solver/time loop and the 1D saturnBurger solver are in place. The 1D Burgers solver is registered in the CLI and validated against the exact traveling wave (second order, rank independent). 2D/3D Burgers, implicit time schemes and the heat solver follow.

What v1 is

area decision
mesh structured hexahedral Gmsh .msh; 2D is one cell thick
state collocated cell-centred velocity vector and dynamic pressure
coupling Rhie–Chow face flux; SIMPLE/PISO
linear algebra PETSc
YAML yaml-cpp 0.8, generated templates, strict validation
units SI only in v1.0
solvers saturnBurger (1D), then heat, Stokes, incompressible
extension copy a solver under src/solvers/saturn<Name>, add addSolver(<name>)
