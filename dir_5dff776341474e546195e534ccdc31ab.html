Detailed Description

linalg

Library target: saturnLinAlg (alias saturn::LinAlg).

PETSc is the linear-algebra backend. This module wraps it so solvers never call PETSc directly.

Implemented

  • PetscScope — initializes PETSc once after MPI and finalizes it on scope exit.
  • petscCheck / SATURN_PETSC_CHECK — converts a PETSc error code into a C++ exception with the failing expression and source location.
  • KspSolver — RAII KSP/PC wrapper with iteration count and residual norm.
  • CMake discovery: find_package(PETSc) with a pkg-config fallback for Debian.
  • testSaturnPETSc — 1D Poisson order, 3D Poisson with CG + GAMG, and an all-Neumann nullspace test on 1/2/4 ranks.

The Phase 0 tests use PETSc DMDA only as a smoke test. The production finite-volume matrix assembler is the next slice.

Next

  • LinearSystem and matrix assembly from LocalMesh face coefficients.
  • Poisson assembler with Dirichlet/Neumann rows and RHS.
  • All-Neumann pressure nullspace.
  • Block/multi-RHS momentum systems.
  • PETSc fieldsplit/Schur for Stokes.
  • True residual and iteration diagnostics.

Boundaries

  • No PETSc calls in Kokkos kernels.
  • No home-grown Krylov solver.
  • A failed solve is an error in validation runs, not a warning.
  • saturnCore does not link PETSc; only saturnLinAlg and solvers do.

Tests

ctest --preset petsc

The tests run under mpirun -np 1/2/4. See docs/guides/petsc.md and docs/theory/poisson.md.
