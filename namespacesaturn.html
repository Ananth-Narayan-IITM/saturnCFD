void saturn::burgersFlux ( const CellField & u,
FaceField & flux,
const LocalMesh & mesh,
ConvectiveScheme scheme = ConvectiveScheme::Rusanov,
Limiter limiter = Limiter::Minmod )

Inviscid Burgers flux f(u) = u^2/2 through every face.

  • Rusanov: local Lax–Friedrichs with the cell values.
  • Muscl: Rusanov with MUSCL-reconstructed left/right states.
  • Upwind: Godunov flux from the two cell values.

u must have one component and two ghost layers for MUSCL. This operator provides the convective part only; add diffusion and sources in the solver.

◆ convectiveFlux()

void saturn::convectiveFlux ( const FaceField & normalVelocity,
const CellField & phi,
FaceField & flux,
const LocalMesh & mesh,
ConvectiveScheme scheme,
Limiter limiter = Limiter::Minmod )

Convective flux per unit area through every face of every owned cell.

normalVelocity is positive along the outward face normal. phi is the transported scalar; flux receives u_n * phi_face.

  • Upwind: first-order upwind face value.
  • Rusanov: scalar Rusanov flux. For one wave speed this is algebraically the upwind flux; it is kept for the system extension.
  • Muscl: limited linear reconstruction of the upwind cell value. Use limiter to select minmod, van Leer or superbee.

Physical-boundary faces use the first-order upwind value; the reconstruction is applied on internal and periodic faces. MUSCL requires two ghost layers.

◆ fillBoundaryGhosts()

void saturn::fillBoundaryGhosts ( CellField & field,
const LocalMesh & mesh,
const std::vector< BoundaryCondition > & conditions )

Fill physical-boundary ghost cells after the periodic/partition halo.

  • Periodic directions are skipped: FieldHalo already filled them.
  • Inactive directions on a 2D mesh are skipped.
  • Dirichlet: ghost = 2*value - owner, so a face value interpolated with equal weights is exactly the boundary value.
  • Neumann: ghost layer l = owner + 2*l*d*g, where d is the owner-centroid to face-centroid normal distance and g is the outward normal derivative. The first layer gives the usual mirrored ghost; higher layers are filled for the two-layer MUSCL stencil.

The callback runs on the host in this CPU-first slice; the field is copied through its host mirror, which is an alias on a host Kokkos build.

Corner ghosts (two or three boundary directions at once) are not filled; the current gradient/divergence stencils only read face-neighbour ghosts. A higher-order reconstruction that needs corner ghosts must extend this.

Linear cell-to-face interpolation for every face of every owned cell.

Internal faces whose two cells are both owned use centroid distances; faces touching a ghost use equal weights. Equal weights are exact on a uniform mesh and for the mirror ghosts used by Dirichlet/Neumann fill. A general non-uniform partition-boundary weighting is a later refinement.

◆ laplacian() [1/2]

void saturn::laplacian ( const CellField & phi,
CellField & out,
const CartesianGeometry & geom )

Orthogonal (seven-point) Laplacian on a uniform Cartesian block.

For each owned cell P:

(L phi)_P = sum_d (phi_{P+e_d} - 2 phi_P + phi_{P-e_d}) / h_d^2

Ghost values must already be filled (periodic halo or physical BC). Only owned cells are written. out must be a distinct field.

◆ laplacian() [2/2]

void saturn::laplacian ( const CellField & phi,
FaceField & face,
CellField & grad,
CellField & out,
const LocalMesh & mesh )

Non-orthogonal corrected Laplacian on a structured LocalMesh.

The face-normal gradient is

grad(phi)_f . n = [(phi_N - phi_P) - d . grad_tang(phi)_f] / (d . n)

where d = x_N - x_P and grad_tang is the tangential part of the interpolated cell gradient. On an orthogonal mesh the correction vanishes.

face (one component) and grad (three components) are caller-owned workspaces and are overwritten. out must be a distinct field.

Internal owned-owned faces use the interpolated cell gradient. Faces that touch a partition or periodic ghost use the owner gradient; the ghost centroid is available in LocalMesh. Physical-boundary faces use the mirror ghost at 2d and no correction.

Build a structured hexahedral box.

nx, ny, nz are the cell counts in each direction. lo and hi are the opposite corners. shear shifts x by shear*(y - lo.y), producing a non-orthogonal parallelepiped; the default is an orthogonal box.

The returned mesh has geometry computed, boundary patches named xmin/xmax/ymin/ymax/zmin/zmax, and a structured (i,j,k) index. Throws std::invalid_argument for non-positive extents.
