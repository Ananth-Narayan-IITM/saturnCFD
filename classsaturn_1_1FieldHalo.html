Detailed Description

Kokkos halo exchange for a CellField.

The operation list still comes from the backend-agnostic HaloExchange. This adapter performs:

device pack -> host mirror -> MPI_Isend/Irecv -> device unpack

Host-staged MPI is the portable first implementation. A GPU-aware path can replace the mirror without changing this interface. Buffers are allocated once in the constructor, not inside a time loop. The referenced HaloExchange (and its MeshPartition) must outlive this object.
